# IBM Plex Sans Arabic

Vendored so Arabic typography (spec §7) works offline and on first launch, and so
the app does not fetch font binaries from a mutable CDN ref at runtime.

- **Source:** https://github.com/google/fonts/tree/main/ofl/ibmplexsansarabic
- **Retrieved at commit:** `702964cf46bd1bf33d0745d24bbaac33edf8b8af`
- **Version:** 1.101 — Copyright © 2017 IBM Corp., Reserved Font Name "Plex"
- **Licence:** SIL Open Font License 1.1 — full text in `OFL.txt`

Weights vendored: Regular (400), Medium (500), SemiBold (600), Bold (700).
Latin faces are not vendored; Latin text uses the system font.

To update, re-download the four `.ttf` files and `OFL.txt` from the path above
and record the new commit SHA here.
